# GRAPH MAKER

This project contains a Python script to generate network metric graphs from CSV data.

Run with:
- `python stats_app_ping_singal_v3.py` (defaults to `week10_26.csv`)
- `python stats_app_ping_singal_v3.py <filename_without_csv_extension>`

Input CSV is read from either repo root or `5G-Seagul_data/`.
Generated charts are saved under `graphs/<filename>/`.
